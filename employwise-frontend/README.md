# 🚀 EmployWise Frontend Application

This is a **React-based User Management System** where users can:
- **Login**
- **View a list of users**
- **Edit user details**
- **Delete users**

The application interacts with the **Reqres API** (`https://reqres.in/api`) for user data.

---

## 📌 Features
 User Authentication (Mock Login)  
 List Users from API  
 Edit User Details  
 Delete Users
