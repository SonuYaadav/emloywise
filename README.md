EmployWise is a user management system built using React.js, designed for handling user data. This project provides functionalities to login, view users, edit user details, and delete users, making it a simple yet effective CRUD (Create, Read, Update, Delete) application.

It uses Reqres API (https://reqres.in/api) as a mock backend to fetch and update user information. The interface is designed with React Router for navigation and Axios for API communication.

🔹 Key Features:
✅ Login System (Mock authentication)
✅ User List (Fetched from API)
✅ Edit User Information (Update user details)
✅ Delete Users (Remove users from the list)
✅ Responsive & Clean UI (Styled with CSS)

This project serves as an excellent practice for working with React, API calls, and CRUD operations.
